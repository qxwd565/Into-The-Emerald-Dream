# Into-The-Emerald-Dream

HSdeck schema 1 카드 API입니다. 최초 추가 날짜의 스펙은 `data/<카드ID>.json`의 `card`에 적고, 이후 패치는 `card.patches`에 **변경한 필드만** 저장했습니다. 날짜는 한국 시간(Asia/Seoul)입니다.

- `cards.json`: 현재 카드 스펙 및 기존 원화 URL
- `render.json`: 현재 스펙 + 과거 날짜별 차이값
- `history.json`: 구버전 플러그인 호환
- `release-policy.json`: 본 세트, 미니세트, 선행 배포 카드 날짜

최초 값 중 공식 패치로 확인하지 못한 내용은 `card.initialSpecStatus`를 통해 잠정으로 표시합니다. **기존 art/golden 원화 및 황금 애니메이션은 그대로 보존했습니다.**


## API 편집 지침 (2026-11-14)

- 필수 공개 데이터: `cards.json`(카드 ID·현재 목록), `data/<CARD_ID>.json`(카드별 실제 한국 최초 사용일과 변경 기록), `art/`(일반 카드), `golden/`(황금 원화·애니메이션), `frame/`(프레임·재질·셰이더·텍스처). 원본이 없는 자산은 새로 꾸며 만들지 않습니다.
- 중복 `render.json`, `history.json`, `*-date.json` 등 구형 집계물은 저장소에 커밋/배포하지 않습니다. 필요하면 임시 빌드 산출물로만 사용합니다. 추가 schema/호환 래퍼도 금지합니다.
- 날짜별 원본이 아닌 `data/` 파일은 필드·기록을 보존한 무손실 변환 후 사용합니다. 한국 기준 실제 사용 가능일(베타 북미 시간 환산, 모험 지구 개방, 이벤트 개시, 부모가 생성하는 토큰)을 확인하고 추정값을 사실로 바꾸지 않습니다.
- 후속 변경은 바뀐 필드만 기록합니다. 잘못된 선행 날짜 키는 삭제·통합하고, 표시용 개행은 `<br></br>`를 사용합니다. 황금/프레임 바이너리 및 원시 증거를 임의 수정하지 않습니다.
- `release-policy.json`, 빌더 `tools/`, 검증용 `.github/` 등은 실제 참조가 있는 한 보존합니다. 개발용 임시 출력은 공개 API를 오염시키지 않게 관리합니다.
